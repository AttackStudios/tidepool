Before you install

Windows will warn you

The build is unsigned, so SmartScreen shows a blue box on first run. Choose More info → Run anyway. Microsoft removed the instant bypass that code signing used to buy, so a certificate would cost money and still show the same prompt until download volume builds reputation.

Installer or portable?

The installer sets up shortcuts and keeps itself updated. The portable zip runs from a folder and touches nothing else — handy on a shared machine, but it will not auto-update.

About the macOS build

Surf Sandbox is a Windows game, so the macOS build exists for development rather than play. You can browse mods and manage profiles, but there is no game for it to launch.

What it needs

Windows 10 or later, 64-bit. About 250 MB of disk. No account, no telemetry, and it never touches your game install — mods live inside profiles.
