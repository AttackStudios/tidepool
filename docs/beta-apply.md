# 🌊  TidePool Beta
### Apply to test pre-release builds
-# Beta testers get builds before anyone else, and their reports decide what ships.
━━━━━━━━━━━━━━━━━━━━━━━━━━

**How it works**
-# Post the form below in this channel. Staff read every application by hand. If you're in, you'll get the **Beta Tester** role and access to the beta channel, where each new build is posted with a download.

**Copy this, fill it in, post it**
```
Discord name:
Steam name:
Do you own Surf Sandbox (or will you on launch day)?
Windows version:
Have you modded games before? (BepInEx, r2modman, Thunderstore, none is fine)
What do you want to test?
Can you include logs and steps to reproduce in a bug report?
```

**What actually gets you in**
-# Not experience. Willingness to run the build and say plainly what broke. "I clicked install and got this error" is worth more than a long list of games you've modded.

**Ground rules for testers**
-# **1 ·** Pre-release builds stay in the beta channel. Don't reupload or share them anywhere.
-# **2 ·** Report bugs in the beta channel, not in help — it keeps help clear for released builds.
-# **3 ·** Builds are unfinished by definition. Export your profiles before testing one.
